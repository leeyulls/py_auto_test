# User Preferences & Deployment Guidelines

## 1. GitHub & Streamlit Cloud 배포 규칙
- **저장소 공개 범위(Visibility)**: Streamlit Community Cloud의 무료 퍼블릭 앱 호스팅은 GitHub 저장소가 **Public** 상태여야 웹훅 및 최신 커밋 자동 빌드/배포가 정상 연동됩니다. (Private 전환 시 Streamlit 연동 차단 주의)
- **배포 갱신**: GitHub push 후 Streamlit Cloud 반영은 웹훅 전송 및 컨테이너 리빌드를 통해 이루어집니다.

## 2. UI/UX 디자인 원칙 (간결미 & 모바일 퍼스트)
- **불필요한 개발자성 설명 배제**: API 키 상태 점검, raw 파일 경로, 장황한 보안 정책 문구, 기술적 사후 감사 용어 등 사용자 관점에서 불필요한 텍스트는 전면 제거하고 직관적인 지표와 핵심 인사이트만 제공합니다.
- **모바일 화면 최적화**: 가로로 4~5개 컬럼을 욱여넣지 않고, 최대 2~3열 또는 반응형 단일 컬럼으로 깔끔하게 배치합니다.
- **사이드바 기본 숨김**: `initial_sidebar_state="collapsed"`를 기본값으로 유지하며, 상단 토글 버튼을 통해 필요할 때만 열리도록 유지합니다.
- **모듈러 확장성**: 금융/브리핑 외에도 사용자가 필요로 하는 다양한 업무 화면(스케줄러, 메모, 파이프라인 관제 등)을 독립된 모듈 탭 형태로 손쉽게 확장할 수 있는 구조를 유지합니다.
